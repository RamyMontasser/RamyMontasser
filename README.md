## MotoVerse

<div align="center">

**Flutter Graduation Project**

</div>

MotoVerse is a mobile application designed around automotive services, connecting car owners with service providers.

The Flutter application includes authentication, identity verification, service center discovery, maps, service requests, offers, real-time chat, and reviews.

**Built with**

`Flutter` `Dart` `Bloc/Cubit` `Dio` `REST API` `WebSockets` `Firebase`
